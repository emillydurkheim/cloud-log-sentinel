# Cloud Log Sentinel: Análise de Ameaças com IA (Google Cloud + Gemini)

Este projeto demonstra a integração entre **Cibersegurança**, **Computação em Nuvem** e **Inteligência Artificial Generativa** para automatizar a análise de logs de acesso e detectar ameaças em tempo real.

## Funcionalidades
- **Ingetão de Logs:** Leitura de eventos de acesso e autenticação no formato JSON.
- **Análise Inteligente:** Processamento automatizado utilizando a API do Google Gemini.
- **Detecção de Ameaças:** Identificação de padrões como ataques de Força Bruta (Brute Force), acessos não autorizados e comportamentos anômalos.
- **Relatório Automatizado:** Geração de diagnósticos com classificação de risco (Baixo, Médio, Alto) e recomendações práticas de mitigação.

## Tecnologias Utilizadas
- **Linguagem:** Python 3.14
- **IA / Cloud:** Google GenAI SDK (Gemini API)
- **Conceitos de Segurança:** Log Analysis, IAM, Mitigation Policies
